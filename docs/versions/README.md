## Version Numbering

Lanflix follows [Semantic Versioning](https://semver.org/):

```
MAJOR.MINOR.PATCH

Example: 0.3.2
- 0 = Major version (pre-1.0 = in development)
- 3 = Minor version (new features)
- 2 = Patch version (bug fixes)
```

### Version Guidelines

**Major (1.0, 2.0, 3.0)**
- Breaking API changes
- Major architecture changes
- Significant feature overhauls

**Minor (0.1, 0.2, 0.3)**
- New features
- Non-breaking API additions
- Significant improvements

**Patch (0.3.1, 0.3.2)**
- Bug fixes
- Performance improvements
- Documentation updates
- Minor tweaks

## Release Schedule

- **Major Releases**: Annually
- **Minor Releases**: Every 3 months
- **Patch Releases**: As needed
