Lanflix is a powerful, self-hosted streaming media server that brings your entire library to life. Designed with a premium, modern interface, it seamlessly integrates with your existing media stack (Sonarr, Radarr, Prowlarr) to provide an automated and beautiful viewing experience.

## 🚀 Getting Started (Windows)

The easiest way to get started is using our pre-built Windows release.

1.  **Download**: Go to the [Releases](https://github.com/JarlTheGamer/LanFlix/releases) page.
2.  **Extract**: Download the latest `Lanflix.WebApi.exe` and extract it to a folder.
3.  **Run**: Double-click `Lanflix.WebApi.exe` to start the server.
4.  **Browse**: Open your browser and navigate to `http://localhost:5037`.
