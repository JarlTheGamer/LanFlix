# RipFlix

A cinematic landing screen inspired by modern Netflix UI explorations. The page showcases a hero carousel, responsive navigation and a curated watch row with elevated glassmorphism styling.

## Getting started

Open `index.html` in your browser or serve the folder with your favorite static server:

```bash
python -m http.server 5173
```

Then visit [http://localhost:5173](http://localhost:5173) to explore the interface.

## Features

- Animated hero section that swaps featured titles from the navigation controls
- Responsive top navigation with frosted glass styling
- Spotlight carousel cards that filter by category tabs
- Pure HTML, CSS and vanilla JavaScript with zero build tooling required
