How to handle media playback

⚠️ Warning: Custom Mode

Custom mode may not work with all footage. Some codec combinations can cause playback issues or seeking problems. Use Auto mode for best compatibility.

Convert incompatible audio codecs to AAC (Custom mode only)

Convert incompatible video codecs to H.264 (Custom mode only)

Use GPU (NVIDIA NVENC) for faster transcoding

Balance between speed and quality (p1=fastest, p7=best quality)

Playback Modes:

Auto: Automatically detects what's needed - Direct Play, Remux (container change), Direct Stream (audio only), or Transcode (full).
Direct Play: Stream files as-is (fastest, no transcoding, requires compatible codecs).
Direct Stream: Transcode audio only, copy video (for incompatible audio like DTS/AC3).
Transcode: Full video+audio transcoding (slowest, works with everything).
Seeking works in all modes. Hardware acceleration uses GPU for 10-20x faster encoding.
